Brightloop – Subscription Management System

Brightloop is a Django-based web application designed to simplify subscription management for businesses. It helps manage products, subscription plans, customers, quotations, invoices, discounts, and payments through a centralized platform.

Features

Product and subscription plan management

Customer and user management

Quotation generation and management

Subscription tracking

Invoice generation and management

Discount and tax management

Payment tracking

Role-based access management

Technologies Used

Backend: Python, Django

Frontend: HTML, CSS, Bootstrap

Database: SQLite

Version Control: Git and GitHub

Installation and Setup

Clone the repository:

git clone https://github.com/rahulkrishna-s/brightloop-subscription-system.git

Navigate to the project directory:

cd brightloop-subscription-system

Create a virtual environment:

python -m venv venv

Activate the virtual environment:

Windows:

venv\Scripts\activate

Linux/macOS:

source venv/bin/activate

Install dependencies:
pip install -r requirements.txt
Apply database migrations:
python manage.py migrate
Start the development server:
python manage.py runserver
Open your browser and visit:
http://127.0.0.1:8000/
